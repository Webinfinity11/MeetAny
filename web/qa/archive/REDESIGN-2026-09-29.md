# MeetAny B2B redesign — 2026-09-29

The final direction retains the blue identity and 3D categories, with a new discovery layout and natural Georgian copy. Company facts/counts come from the existing data. Temporary presentation photos do not replace uploaded logos or write to the database. The beta label is removed.

## Mobbin references

References were searched through the connected Mobbin integration and visually inspected. Their hierarchy and interaction patterns informed the composition; no reference screen assets were copied into the product.

- [Faire discovery](https://mobbin.com/screens/63f8c31f-e379-484b-bfe5-37615064fc25): split photo/text hero and category discovery.
- [Fiverr Business](https://mobbin.com/sites/sections/eb31b7d9-3eed-49e2-b439-0f79634ab0b1): prominent task search.
- [Upwork jobs](https://mobbin.com/screens/2f9be872-82d0-4446-87de-7d04b7f3c2d8): readable request rows and separate filter rail.
- [Fiverr profile](https://mobbin.com/screens/1ce85378-3f18-4ce9-b9a8-66cabce9f6bb): distinct contact area and profile sections.

## Final behavior

- Home has supplier/work search modes, role/category discovery, three live company cards, a request starter and a three-step explanation. The previously large duplicate request board is replaced by a short title/city form. Validated starter values carry into the full form and through sign-in; submission still requires explicit confirmation. This does not persist all full-form draft fields or file uploads across authentication.
- Company directory separates filters from results. Cards expose services, coverage, profile and phone actions; photos have bounded aspect ratios. The search panel is above the result cards, fixing the reported overlap.
- Requests have a desktop filter rail, mobile filter sheet, readable descriptions and offer/deadline metadata. The selected sort is honored without synthetic VIP/TOP ranking.
- Company profiles use one compact logo/name/industry block. The repeated stock-photo banner was removed following feedback. Contact, service coverage and address are grouped in a sidebar (stacked on mobile); services remain readable rows. Product-photo rendering uses a consistent contained frame when structured photo data is available; no product data was invented.
- Header and footer use the shared blue, spacing and control styles. Footer links are grouped by task. Decorative arrows and the beta label are removed; functional back-navigation/icons remain.
- Guests can browse and reveal public phone numbers. Messaging explicitly prompts sign-in and preserves the current profile destination. Header notifications/chat and private account navigation appear only for signed-in users. Own company profiles expose editing instead of self-contact controls. Footer/home calls to action adapt to account state; signed-in users are not prompted to register again.
- Registration now honors the same validated local `next` path as login when it produces an authenticated session.
