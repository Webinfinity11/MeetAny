# MeetAny feature priorities — 2026-09-23

Desk research of official product documentation, not user interviews or evidence of conversion uplift. Recommendations below are our interpretation for MeetAny's Georgia/international supplier-connection objective. Existing request publishing, offers, search, filters and phone reveal are already implemented; these proposals extend them.

1. **Relevant request alerts.** Let suppliers subscribe to categories and service locations with controllable frequency. Start with explicit rules and show why an alert matched. Measure time to first relevant response and opt-outs. Europages documents matching and email notifications: https://help.europages.com/en/supplier/europages-request-hub
2. **Saved supplier lists and comparison.** Save companies into a project and compare 2–3 on services, location/coverage, business type and contact language. Hide unavailable comparison fields rather than infer facts. Thomas documents saved lists and side-by-side comparison: https://help.thomasnet.com/save-shortlist-suppliers and https://help.thomasnet.com/compare-suppliers
3. **One request to selected suppliers.** Extend our existing public request with deliberate selection of recipients and private delivery status; never send automatically merely because a company appears in search. Thomas supports contacting selected suppliers through one form; Alibaba documents RFQ sourcing: https://help.thomasnet.com/save-shortlist-suppliers and https://buyer.alibaba.com/page/HowItWorks/Page.html
4. **International discovery fields.** Add country, delivery/service countries, contact languages and an English profile option; later add translations with the original available. This is an inference from our target audience, not a competitor-performance claim. Normalize countries/languages in data before expanding filters. Distinguish company headquarters from destinations served.
5. **Request-linked conversations and attachments.** Keep questions, files and responses tied to one request. Start with a small message thread, then add notifications and moderation/reporting. Europages documents responding with terms and clarifying questions in its Request Hub. Do not add an unrelated social feed.

Suggested order: alerts + saved lists; international data foundation; selected-recipient requests and request-linked conversations. Comparison becomes useful as structured supplier profiles fill out. Validate priorities with 5–8 target buyers/suppliers and measure relevant responses and successful connections rather than raw phone-link clicks. No new feature above has been implemented as part of the admin backend change.

## Save placement review

The first implementation put a standalone bookmark next to the bottom contact/profile actions; the owner rejected this as uncomfortable. Revised pattern: an explicit bookmark + Save/Saved label in the upper company utility area, with a consistent right alignment and a separate profile toolbar. This adapts the documented B2B save patterns; it is not a pixel-for-pixel copy. Sources: https://help.thomasnet.com/save-shortlist-suppliers and https://www.europages.co.uk/inside-business/for-suppliers/tips-strategies/how-does-supplier-search-work-on-europages . The latter explicitly describes profile contact/save controls on the right. The live Europages page did not render in the automated browser; only accessible official documentation and its embedded illustration were inspected, so do not claim live visual parity.
